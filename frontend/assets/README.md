# assets

Ce dossier est prévu pour des images locales que vous voulez utiliser vous-même dans le site (par exemple des photos de la classe, ou des illustrations que vous avez le droit d'utiliser).

Le site ne fournit aucune image par défaut ici : les modules "Générateur de mèmes" et "Image → Histoire" fonctionnent avec les images que chaque utilisateur importe depuis son propre appareil, ou avec le bouton "Image aléatoire" du module Image → Histoire, qui va chercher une photo libre de droits sur Picsum (photos issues d'Unsplash, pas d'image générée par IA).

Pour utiliser une image de ce dossier dans une page, placez le fichier ici puis référencez-le avec un chemin du type `assets/nom-du-fichier.jpg`.
